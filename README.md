# NLP Chatbot

An NLP-powered chatbot designed to understand user messages, classify intents, and generate relevant responses using Natural Language Processing and Machine Learning.

## Project Objectives

- Process and normalize user input.
- Identify user intent using a machine learning model.
- Generate appropriate responses based on detected intent.
- Provide a REST API using FastAPI.
- Build an interactive frontend using React and TypeScript.
- Evaluate model performance and test API functionality.

## Technology Stack

- **Language:** Python
- **NLP:** NLTK, scikit-learn
- **Machine Learning:** TF-IDF, Logistic Regression
- **Backend:** FastAPI, Uvicorn
- **Frontend:** React, TypeScript, Vite
- **Testing:** Pytest
- **Version Control:** Git and GitHub
